# Implementations

## Research Bridge standalone skill — 2026-10-18

`SKILL.md` is the public entry contract for a host-neutral cross-domain literature discovery workflow. It uses mechanism-first discovery, claim-level evidence boundaries, direct article links, plain-language explanations, one crisp stack action, one bounded test, and optional inactive motif suggestions. The public repository contains no scheduler, notification route, persistent state, private paths, internal job identifiers, personal data, or production-label activation. `references/lbd-method.md` and `references/scenario-matrix.md` are the only supporting method files; `agents/openai.yaml` carries Codex metadata. The MIT license applies to the seven-file standalone repository.
